# Enterprise Hospital Management System

A production-grade, multi-container **Hospital Management System** designed with modern 3-tier architecture for high availability, secure patient record tracking, and automated CI/CD deployment pipelines.

---

## 🏗️ System Architecture & Tech Stack

* **Frontend:** React.js / Next.js (Modern Responsive UI)
* **Backend:** Node.js (Express) & Python FastAPI (Microservices API)
* **Database:** MySQL / PostgreSQL with encrypted patient logs
* **Containerization:** Docker & Docker Compose (Multi-container setup)
* **DevOps & CI/CD:** GitHub Actions automated deployment to AWS EC2

---

## ✨ Core Features

* **Role-Based Access Control (RBAC):** Separate secure portals for Admins, Doctors, Nurses, and Patients.
* **Appointment Scheduling:** Real-time doctor availability slot booking and automated notifications.
* **Electronic Health Records (EHR):** Secure storage of patient medical history, prescriptions, and lab reports.
* **Billing & Pharmacy Management:** Automated invoice generation and medicine stock tracking.
