# Enterprise Hospital Management System

Welcome to the **Enterprise Hospital System**! This is a production-ready, multi-container Hospital Management Application built for scalability and automated DevOps pipelines.

---

## 🚀 Tech Stack
* **Frontend:** React.js, Tailwind CSS
* **Backend:** Node.js (Express) / Python FastAPI
* **Database:** MySQL / PostgreSQL
* **Containerization:** Docker & Docker Compose
* **CI/CD:** GitHub Actions (Automated EC2 Deployment)

---

## ✨ System Modules
* **User Authentication:** Role-based access control (Admin, Doctor, Patient).
* **Appointment Management:** Real-time doctor slot scheduling.
* **Patient Records:** Secure medical history tracking and prescriptions.
* **Billing & Invoicing:** Automated treatment billing system.
